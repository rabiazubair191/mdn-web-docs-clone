# MDN Web Docs - Clone UI

A responsive frontend recreation of the **MDN Web Docs** documentation page, built using foundational web design practices.

## 📌 Features

- **Responsive Header & Navigation:** Includes logo, navigation links, and desktop/mobile navigation structure.
- **Multi-Column Documentation Layout:** Sidebar navigation, main content body, and right-hand article table of contents.
- **Dark Theme Styling:** Styled to closely match MDN Web Docs' signature dark visual aesthetic.
- **Responsive Layout:** Responsive layout behavior for smaller screens using media queries.

## 🛠️ Tech Stack & Concepts Applied

- **HTML5:** Semantic elements (`<header>`, `<nav>`, `<aside>`, `<main>`, `<footer>`).
- **CSS3:**
  - CSS Flexbox (for aligned layouts and responsive component flows)
  - CSS Positioning (`relative`, `absolute`, `fixed`)
  - CSS Pseudo-classes (`:hover` state interactions)
  - CSS Media Queries (responsive design adjustments)
